# ИИ-помощник и Telegram-боты: памятка для следующего чата

Памятка для Claude и для себя: что где лежит, как менять, на чём уже обжигались.
Секретов (ключей, токенов, паролей) здесь нет и быть не должно — они только в `.env` на сервере.

## 1. Что есть

Один помощник, два профиля — `sales` (продажи) и `finance` (финансы). Работает в трёх местах:
дашборд «Продажи по дням», дашборд «Управленческий пакет» и **два Telegram-бота**.

| Бот | Профиль | Служба на сервере | Токен в `.env` |
|---|---|---|---|
| Продажи (`tr_sales_bot`) | `sales` | `ts-bot@sales` | `TELEGRAM_BOT_TOKEN_SALES` |
| Финансы (`tr_finance_bot`) | `finance` | `ts-bot@finance` | `TELEGRAM_BOT_TOKEN_FINANCE` |

Оба бота — один и тот же код, запуск `python manage.py assistant_bot --profile sales|finance`.
Правка в коде бота меняет сразу оба; различия — только в словарях по ключу профиля.

## 4. Кнопки в Telegram — как быстро добавить

Всё в `assistant_bot.py`, оба бота сразу.

- **Нижнее меню** (постоянные кнопки): словарь `MENU` + раскладка в `keyboard()`.
  Нажатие приходит обычным текстом и превращается в команду строкой
  `text = {v: "/" + k ...}` в `handle()` — новой кнопке нужна ветка `if text == "/ключ"`.
- **Примеры вопросов** (кнопки под сообщением): список `EXAMPLES[профиль]` —
  пары `(подпись кнопки, вопрос)`. Подпись до ~20 символов, иначе Telegram обрежет.
  Больше ничего менять не нужно.
- **Кнопки под ответом**: `ANSWER_KB`. `callback_data` — короткий код; что он значит —
  в `on_button()` (сейчас `xl` → «Пришли это в Excel», `new` → новый разговор).
- **Строка «что сейчас делаю»**: словарь `STEPS` — `имя инструмента → текст`.
  Добавили инструмент в `tools.py` — добавьте строку сюда, иначе будет «Смотрю данные».
- Имя, аватарка, картинка-заставка — только через @BotFather
  (`/setname`, `/setuserpic`, `/setdescriptionpic`). Описание и «о боте» бот ставит сам
  при запуске (`DESCRIPTION`, `ABOUT`).

## 5. Доступ коллег

Коллега открывает ссылку на бота → «Старт» → заявка появляется в админке
«Помощник в Telegram: доступ» → вписать «Кто это», поставить галочку, «Сохранить».
Бот сам пишет человеку, что доступ открыт. Кнопка «Печать списка доступа» — список
тех, у кого доступ есть, по ботам. Ссылки на ботов в админке берутся из
`TELEGRAM_BOT_USERNAME_SALES/_FINANCE` (по умолчанию `tr_sales_bot`, `tr_finance_bot`).

## 6. Секретики и грабли

- **Сервер в РФ.** Claude и Telegram ходят через туннель: `ANTHROPIC_PROXY` и
  `TELEGRAM_PROXY` = `socks5://127.0.0.1:1080`, служба `claude-tunnel`. Системные
  `HTTP_PROXY/HTTPS_PROXY/ALL_PROXY` задавать нельзя — сломается загрузка данных WB.
  «Нет связи с Claude API» → `sudo systemctl status claude-tunnel`.
- **Ботов перезапускать по очереди** с паузой 15 с: при одновременном старте оба
  открывают DuckDB и один падает с «Conflicting lock» (поднимется сам, но позже).
- **Бот обрабатывает сообщения по одному.** Длинный вопрос одного человека задерживает
  ответ другому в том же боте.
- **Параметры `Bot.call()`** идут в Telegram как есть; служебный таймаут называется
  `_wait` (имя `timeout` занято параметром getUpdates).
- **Таблицы.** Помощник пишет markdown-таблицу, `_table()` делает из неё `<pre>` с
  выровненными колонками; `**` внутри ячеек вычищается. Широкие таблицы на телефоне
  переносятся — длинные таблицы лучше отдавать в Excel.
- **Защита от выдуманных цифр** (`llm.py`):
  1) ответ с цифрами без вызова инструмента → повтор с обязательным инструментом;
  2) год не назван, а запрошены данные старше 12 месяцев → инструмент отклоняет вызов
     и требует текущий год (`_stale_year`; снимается, если в диалоге есть год, «год
     назад», «N месяцев» и т. п.).
- **Незакрытый месяц.** ТБУ считается по среднему за 3 последних закрытых месяца, факт
  месяца показывается отдельно; ответ обязан начинаться с этой оговорки
  (`finance_extra.scenario_report`, блок «ПЕРИОД ЦИФРЫ» в `prompt.py`).
- **Недели** — календарные пн–вс, готовые даты даёт `_calendar()` в промпте.
- **Названия WB:** `retail_price` — до СПП, `retail_amount` — после СПП.
- **Чего помощник не раскрывает:** зарплаты по людям, схему БД, код, ключи; ИП и
  физлиц маскирует до «ИП/физлицо (ИНН …1234)».
- **Меню после обновления** бот ставит сам при первом сообщении человека после
  перезапуска; `/start` нажимать не обязательно.
- **Проверка без сервера.** У Claude в папке проекта нет Django и DuckDB: доступны
  `py_compile`, проверка шаблонов через `PYTHONPATH=venv/lib/python3.12/site-packages`
  и прогон логики на заглушках. Реальные цифры проверяет только Дарья.
- **Git.** Команда `git status` из песочницы Claude оставляет в `.git` пустые
  `index.lock*` — лучше не вызывать; если остался `index.lock`, переименовать.

## 7. Инструкции для коллег (Excel и PDF)

Две инструкции: «Продажи» и «Финансы». Содержание — в одном месте, словари `SALES` и
`FIN` в `instructions/mk.py`; PDF берёт текст оттуда же.

```
python mk.py     # два .xlsx (openpyxl)
python pdf.py    # два .pdf: HTML → PDF через Playwright/Chromium, A4, scale 0.88
```

Пути вывода в скриптах — `/mnt/user-data/outputs/` (песочница Claude), при запуске у
себя заменить. Оформление — тёмно-зелёное (`#1F5E4E`, `#2F6656`), без скруглений,
3 страницы: что это и как спросить → что умеет и чего не делает → примеры вопросов.
После изменений в боте (кнопки, новые отчёты) обновить `SALES`/`FIN` и пересобрать.

## 8. Стиль

- Фирменный тёмно-зелёный `#2F6656` / `#1F5E4E`, акцент для «ждёт» — `#B45309`.
  Углы прямые, переключатели без скруглений.
- Комментарии в коде — короткие и по делу, по-русски.
- Отвечать Дарье по-русски и кратко.

## 9. Отложено

Платёжный календарь (нужны миграции — пока не делаем); товарные запасы убраны из
мэн пака; правило про «убыток за один день» — не делать.

## 10. Тихий час

С 23:20 до 23:57 по Москве (ночная загрузка данных) боты не принимают вопросы и
отвечают «обновляются данные». Меню и подсказки работают. Время — константа `QUIET`
в `assistant_bot.py`. На помощника в дашбордах не распространяется.

## 11. Журнал вопросов

Модель `TelegramQuestion` (миграция `0009`): кто, когда, бот, текст вопроса, время
ответа, стоимость в $, был ли Excel, была ли ошибка. Ответы бота не сохраняются.
Пишет `Bot.log()` в `assistant_bot.py`; записи старше `KEEP_DAYS` (30) удаляются раз в
сутки при очередном вопросе. Админка «Помощник в Telegram: вопросы» — только чтение
и только суперпользователю; сверху сводка по людям по текущим фильтрам.
