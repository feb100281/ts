# WB API для управленческого учета

_WB API может быть удобным инструментом, так как позволяет загружать работать с данными напрямую минуя портал WB. На основании данных выгрузок можно быстро строить аналитики и PL. Однако есть ряд вопросов которые требуются уточнить что бы отчетность шла в рамках портала WB и бухгалтерии._


## 1. Исходные данные
Нас интересует детализированный отчет о реализации, полученный через WB API.
Источник: https://statistics-api.wildberries.ru/api/v5/supplier/reportDetailByPeriod

__Ограничения WB:__

-	Минимальная дата — 29 января 2024 года
-	Периодичность — день / неделя
-	Интервал между запросами — 1 минута
-	Ограничение — 100 000 строк на запрос

В итоге, чтобы скачать все данные, ушло более 10 часов. Я грузила по дням что бы не зависить от недельных отчетов.

Все raw-данные сохранены в отдельную таблицу PostgreSQL.

__Объем данных__
- Период: 29 января 2024 — 2 февраля 2026
- Всего загружено: 11 833 588 строк.

## 2. Состав данных

Каждый JSON документ содержит от 85 до 90 полей. Поля меняются в зависимости от времени и типа операции. Сделать итоговорую таблицу из выгрузок можно, но нужно постоянно мониторить изменения WB что бы обрабатывать новые поля и изменения методики расчетов. 

Сырые данные отчета представляет собой ненормализированную выгрузку — фактически большое _неструктурированное месиво из данных_.

После загрузки база данных была нормализизирована. Официальная документация WB и документация к WB API противоречива. Оферта так же не дает ответы как использовать полученные данные. Сложно сопоставить поля выгрузки с описанием полей в официальной документации, а так же в официальной документации отсутствуют детали, которые могли помочь корректно разносить данные.

В таблице ниже - mapping полей api и документации к порталу а также вопросы и комментарии.

  is_legal_entity,

  -- prc
  ppvz_kvw_prc,
  ppvz_spp_prc,
  sale_percent,
  acquiring_percent,
  ppvz_kvw_prc_base,
  commission_percent,

  -- FKs
  country_id,
  son_id,
  dtn_id,
  pmt_processing_id,

  -- EAV
  field,
  value,

  loaded_at
)
SELECT
  -- Даты
  (t.row_json->>'date_from')::date              AS date_from,
  (t.row_json->>'date_to')::date                AS date_to,
  (t.row_json->>'rr_dt')::date                  AS rr_dt,
  (t.row_json->>'sale_dt')::timestamptz         AS sale_dt,
  (t.row_json->>'order_dt')::timestamptz        AS order_dt,
  (t.row_json->>'create_dt')::timestamptz       AS create_dt,

  -- IDs / RAW
  (t.row_json->>'rrd_id')::bigint               AS rrd_id,
  (t.row_json->>'nm_id')::bigint                AS nm_id,
  (t.row_json->>'realizationreport_id')::bigint AS realizationreport_id,
  (t.row_json->>'sa_name')::text                AS sa_name,
  (t.row_json->>'shk_id')::bigint               AS shk_id,
  (t.row_json->>'report_type')::bigint          AS report_type,

  -- Прочее
  (t.row_json->>'barcode')::text                AS barcode,
  (t.row_json->>'srid')::text                   AS srid,
  (t.row_json->>'ts_name')::text                AS ts_name,
  (t.row_json->>'currency_name')::text          AS currency_name,
  (t.row_json->>'bonus_type_name')::text        AS bonus_type_name,
  (t.row_json->>'quantity')::int                AS quantity,
  (t.row_json->>'is_legal_entity')::bool        AS is_legal_entity,

  -- prc
  (t.row_json->>'ppvz_kvw_prc')::numeric         AS ppvz_kvw_prc,
  (t.row_json->>'ppvz_spp_prc')::numeric         AS ppvz_spp_prc,
  (t.row_json->>'sale_percent')::numeric         AS sale_percent,
  (t.row_json->>'acquiring_percent')::numeric    AS acquiring_percent,
  (t.row_json->>'ppvz_kvw_prc_base')::numeric    AS ppvz_kvw_prc_base,
  (t.row_json->>'commission_percent')::numeric   AS commission_percent,

  -- FKs
  cc.id                                          AS country_id,
  dso.id                                         AS son_id,
  dtn.id                                         AS dtn_id,
  pp.id                                          AS pmt_processing_id,

  -- EAV
  kv.key                                         AS field,
  ROUND((kv.value)::numeric * 100)::bigint       AS value,

  t.loaded_at                                    AS loaded_at
FROM a t
CROSS JOIN LATERAL jsonb_each_text(t.row_json) AS kv(key, value)
LEFT JOIN wb_dwh.dim_supplier_oper dso
  ON dso.name = NULLIF(btrim(t.row_json->>'supplier_oper_name'), '')
LEFT JOIN wb_dwh.dim_doc_type dtn
  ON dtn.name = NULLIF(btrim(t.row_json->>'doc_type_name'), '')
LEFT JOIN public.corporate_countries cc
  ON cc.name = NULLIF(btrim(t.row_json->>'site_country'), '')
LEFT JOIN wb_dwh.payment_processing pp
  ON pp.name = NULLIF(btrim(t.row_json->>'payment_processing'), '')
WHERE
  (t.row_json->>'date_from') IS NOT NULL
  AND kv.value ~ '^-?\d+(\.\d+)?$'
  AND (kv.value)::numeric <> 0
  AND kv.key NOT IN (
    'quantity',
    'barcode',
    'sa_name',
    'report_type',
    'ts_name',
    'srid',
    'kiz',
    'ppvz_kvw_prc',
    'ppvz_spp_prc',
    'sale_percent',
    'acquiring_percent',
    'ppvz_kvw_prc_base',
    'commission_percent'
  )
  AND kv.key !~* 'id$';
