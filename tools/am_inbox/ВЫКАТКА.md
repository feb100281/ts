# Армения: выкатка на сервер

## 1. Mac
```bash
cd ~/Documents/Projects/ts && source venv/bin/activate
python manage.py makemigrations --check --dry-run    # ждём: No changes detected
python manage.py check                               # ждём: no issues
git push origin armenia
grep AM_UPLOAD_TOKEN .env                            # скопировать строку для сервера
```

## 2. Сервер: копия базы и проверки «до»
```bash
ssh daria@82.202.197.94
cd ~/ts && source .venv/bin/activate
set -a; source .env; set +a

# копия базы
PGPASSWORD="$DB_PASSWORD" pg_dump -Fc -h "$DB_HOST" -p "$DB_PORT" -U "$DB_USER" "$DB_NAME" -f ~/ts_before_armenia.dump
ls -lh ~/ts_before_armenia.dump

# витрины cf_to_csv / pl_for_csv читают выписки напрямую? Ждём 0 и 0
python manage.py dbshell -- -At -c "select pg_get_viewdef('public.cf_to_csv', true)" > ~/cf_to_csv.sql
python manage.py dbshell -- -At -c "select pg_get_viewdef('public.pl_for_csv', true)" > ~/pl_for_csv.sql
grep -c treasury_cfdata ~/cf_to_csv.sql ~/pl_for_csv.sql

# цифры «до»
python manage.py dbshell -- -At -c "select 'cf', company_id, count(*), sum(dt), sum(cr) from gl.normalized_cf group by 2 union all select 'fact', company_id, count(*), sum(dt), sum(cr) from gl.fact group by 2 order by 1, 2" > ~/check_before.txt
```
Если grep показал не 0 — остановиться и прислать оба .sql.

## 3. Сервер: код, ключ, миграции
```bash
git fetch origin && git checkout armenia
echo 'AM_UPLOAD_TOKEN=<строка с Mac>' >> .env
python manage.py migrate
python manage.py check
sudo systemctl restart gunicorn-ts
sudo systemctl restart ts-bot@sales && sleep 15 && sudo systemctl restart ts-bot@finance

# отбор «только РФ» в скриптах /opt/wb_jobs (с резервными копиями)
python tools/am_inbox/patch_etl_gate.py /opt/wb_jobs/*.py
```

## 4. Сервер: цифры «после» — должны совпасть
Обновить витрины GL как обычно, затем:
```bash
python manage.py dbshell -- -At -c "select 'cf', company_id, count(*), sum(dt), sum(cr) from gl.normalized_cf group by 2 union all select 'fact', company_id, count(*), sum(dt), sum(cr) from gl.fact group by 2 order by 1, 2" > ~/check_after.txt
diff ~/check_before.txt ~/check_after.txt && echo "СОВПАДАЕТ"
```

## 7. Уборка
