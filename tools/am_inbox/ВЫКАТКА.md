# Армения: выкатка на сервер

Ветка `armenia` вливается в `daria` (она на сервере). Всё проверено на тестовой базе `ts_test`.
Время: около 30 минут. Делать в спокойное время, не во время ночного расчёта.

## 1. Mac: влить ветку и отправить
```bash
cd ~/Documents/Projects/ts && source venv/bin/activate
git status                                   # README.md и xml_import.py — твои правки, их не трогаем
git checkout daria
git merge --no-ff armenia -m "Армения: учёт, главная книга, пакет по компаниям"
python manage.py check                       # ждём: no issues
git push origin daria
grep AM_UPLOAD_TOKEN .env                    # скопировать строку для сервера
```

## 2. Сервер: копия базы и цифры «до»
```bash
ssh daria@82.202.197.94
cd ~/ts && source .venv/bin/activate
set -a; source .env; set +a

PGPASSWORD="$DB_PASSWORD" pg_dump -Fc -h "$DB_HOST" -p "$DB_PORT" -U "$DB_USER" "$DB_NAME" -f ~/ts_before_armenia.dump
ls -lh ~/ts_before_armenia.dump

python manage.py dbshell -- -At -c "select company_id, chapter, count(*), sum(dt), sum(cr) from gl.fact group by 1, 2 order by 1, 2" > ~/check_before.txt
```

## 3. Сервер: проверить, что скрипты в /opt/wb_jobs не менялись с 14.11
```bash
cd ~/ts && git fetch origin && git checkout daria && git pull
for f in ba_etl.py gl_etl.py accurals/cashbased.py accurals/coa_fixed_cost_per_unit.py \
         accurals/fixed_monthly_sums.py accurals/fixed_total_by_period.py \
         accurals/rent_premises.py accurals/rent_premises_ms.py; do
  git show 4ab84a0:utils/etl/server/$f | diff -q - /opt/wb_jobs/$f >/dev/null && echo "ok  $f" || echo "ИЗМЕНЁН  $f"
done
```
Если хоть один «ИЗМЕНЁН» — остановиться и прислать список: значит, Павел правил скрипт на сервере.

## 4. Сервер: код, ключ, миграции
```bash
grep -q AM_UPLOAD_TOKEN .env || echo 'AM_UPLOAD_TOKEN=<строка с Mac>' >> .env
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py check
python manage.py am_coa                      # счета и статьи для Армении и розницы
python manage.py load_currency_rates --from 2024-12-01 --to "$(date +%F)" --currencies AMD,USD,EUR,KZT
sudo systemctl restart gunicorn-ts
sudo systemctl restart ts-bot@sales && sleep 15 && sudo systemctl restart ts-bot@finance
```

## 5. Сервер: скрипты главной книги (с резервными копиями)
```bash
STAMP=$(date +%Y%m%d)
for f in ba_etl.py gl_etl.py accurals/cashbased.py accurals/coa_fixed_cost_per_unit.py \
         accurals/fixed_monthly_sums.py accurals/fixed_total_by_period.py \
         accurals/rent_premises.py accurals/rent_premises_ms.py; do
  sudo cp /opt/wb_jobs/$f /opt/wb_jobs/$f.bak_$STAMP
  sudo cp ~/ts/utils/etl/server/$f /opt/wb_jobs/$f
done
```

## 6. Сервер: расчёт книги и цифры «после»
```bash
systemctl list-units --all | grep -i -E "accru|gl"   # имя службы расчёта книги («WB Accruals Engine»)
sudo systemctl start <имя службы>.service            # и дождаться: systemctl status <имя службы>
python manage.py dbshell -- -At -c "select company_id, chapter, count(*), sum(dt), sum(cr) from gl.fact group by 1, 2 order by 1, 2" > ~/check_after.txt
diff ~/check_before.txt ~/check_after.txt
```
Для компании 1 строки должны совпасть (кроме начислений «до сегодня» — сдвиг на дни между запусками).
Новых строк компании Армении пока не будет: выписки и продажи ещё не загружены на рабочий сервер.

## 7. Mac: первая загрузка Армении
1. Нажать «Армения — разложить и загрузить». По каждому файлу ждём «✓».
2. На следующий день (после ночного расчёта) — пакет в админке, «Компания: Армения, драмы».

```bash

rm ~/Documents/Projects/ts/analytics/analytics_test.duckdb      # 10 ГБ

```
